# Video folder template

Copy this whole directory to start a video:

    cp -r videos/_template videos/003-my-topic

Then fill files in gate order. `status:` in each front-matter block moves
`todo → drafted → submitted → approved`. Only I set `approved`, and only after
the executive producer says so in chat.

`voiceover.wav` is not stubbed here — a placeholder binary is worse than an
absent one. It is rendered after G3 and lands in this folder alongside its
source text.
